Sites

A rule covers the site and its subdomains, and is matched against the address bar — so a video in an embedded player follows the page it is embedded in. Unchecking a rule suspends it without losing it. Taking a site off the list it is on does that to every rule that covered it — a parent domain's included, so its other subdomains follow; that is switching off under Only these sites, and switching on under Everywhere except these. The opposite direction only ever writes the one site. Turning a site off frees whatever this extension was holding there at once; turning one on catches new blobs, but a video already playing has to be reloaded, because its opening segment is already past.

Memory limits
MB MB

Held in the page's own memory, which is what makes a revoked blob recoverable and a stream saveable at all. Lowering a limit takes effect at once, on pages already capturing. Raising one will not restart a stream that has already stopped — what is kept has to be one unbroken run from the start.
